# Repo Context

## What this project does
This repository contains a browser-based Memory Game, also known as Concentration. The game presents a grid of cards that the player flips over two at a time to find matching pairs. The goal is to clear the board in as few moves as possible while keeping time and score in mind.

## Features in the app
- 4x4 and 6x6 game board options
- Card flip animations
- Move counter
- Timer
- Star rating based on performance
- Best score tracking with local browser storage
- Keyboard support for accessibility
- Responsive layout for desktop and mobile screens
- No external dependencies or framework setup

## Tech stack
This project is built with plain HTML, CSS, and JavaScript. Everything is contained in a single page file, which makes it easy to open directly in a browser or serve locally.
